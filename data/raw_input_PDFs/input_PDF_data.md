1. This folder contains the PDFs of the cases downloaded from the Indian Kanoon website with 
(a) select **Browse judgments**
(b) under HIGH COURTS, select **Delhi High Court** and **Delhi High Court - Orders**
(c) year: 2000-2025 (select one year at a time with the option for **Entire Year**)
(a) search string: **bail application for charge of fraud ORR bail in fraud case**
2. Cases downloaded from Delhi High Court have file names with prefix c such as c00017 and those from Delhi High Court - Orders with prefix codr such as codr00843. The codes wriiten before first underscore in each file name indicates the corresponding *case_id* (followed across all data files and within the codes).
